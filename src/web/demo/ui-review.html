UI review: choose fixes

Each item shows the current look (marked “current”) beside alternatives, in Hal’s real theme colours. Pick one per item and add a note if you like. Your choices collect in the text to paste at the bottom, and they survive a reload.

1. Selection colour

Nothing sets ::selection, so the browser's highlight sits behind coloured text. Drag across the samples, including inside the message box. The last row is a chosen completion: it's already a solid block, so a selection there has to stand out from it.

2. Message box: vertical centring

The buttons make the row 44px tall, but the text box underneath is about 39px tall and sits at the top of it, so the text and caret end up above the button labels. Try one line, then several (Shift+Enter).

3. Tabs: label alignment and the current tab

Tab labels sit at the left of their cell with extra space on the right, so the hover highlight looks off-centre. On touch the cell is 44px wide and the label is squeezed into its left part. Tab 3 is the current tab; hover over the others.

4. Question: layout and Answer button

Right now the field label and help text share a wrapping row with the options, the Answer button looks like one more option, and the × can overlap the question text.

5. Focus style

There are six different focus styles now. Every sample is drawn as if it had focus; press Tab to see the real ones.

6. Notice bar width

Notices have a 0.4rem (about 5.6px) bar on the left; cards, questions and the message box use 3px.

7. Spacing scale

The CSS uses about a dozen different rem values. Choose one scale; each preview spaces the same screen with it.

8. Opening and closing cards

Cards animate their height when they open, but tasks/README.md says animate only opacity, colour and transform. Click a card to try it.

9. Small text

The status row uses 0.85em (about 11.9px), and landscape phones shrink it further, to 11px. The first row in each option is desktop; the second is a landscape phone.
